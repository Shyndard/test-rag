# Technical Specification: Christmas Tree Type 6

## Overview
A wall-mounted half Christmas tree for space-saving decoration.

## Height
- 1.2 meters

## Material
- PVC branches, wooden backing

## Branch Density
- Flat, 400 tips

## Needle Type
- Soft, green plastic needles

## Trunk
- Half-trunk, wall-mountable

## Additional Features
- Easy to hang
- Lightweight design

## Safety
- Secure mounting required
- Keep away from open flames
